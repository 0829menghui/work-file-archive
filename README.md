# 个人模块化工作台

这是一个新的独立项目，用来按账号权限管理不同模块。

当前已经实现两个业务模块：

- `3D 文档归档`: 给对象使用，用来保存 3D 软件工程图、模型源文件、贴图、材质、渲染图、参考图、说明文档等文件。
- `大数据知识库`: 给自己使用，用来直接写大数据开发相关文档、学习笔记、方案、复盘和资料沉淀。

管理员账号可以进入 `系统管理`，创建、修改、停用用户，并为用户分配每个模块的访问权限。
也可以维护模块本身的展示名称、说明和排序。

## 模块权限

每个用户对每个模块都可以单独设置权限级别：

- `无权限`: 用户看不到该模块。
- `仅查看`: 可以查看、搜索、预览、下载，不能新增、上传、编辑、删除。
- `可编辑`: 可以使用该模块内的日常写操作。
- `管理`: 管理员级别权限。

权限不仅在前端隐藏按钮，后端接口也会校验。比如仅查看用户即使直接调用上传、新增、删除接口，也会被拒绝。

- admin 可以修改模块名称、说明和排序。
- 后端接口校验模块权限。

### 3D 文档归档

- 示例 3D 项目初始化。
- 项目列表。
- 项目资料管理：项目名称、客户、状态、备注。
- 项目模板目录树。
- 新建项目。
- 新建目录。

- 文件下载。
- 当前目录打包下载。
- 同名文件上传自动生成新版本。
- 文件详情和历史版本。
- 常见文件在线预览：图片、PDF、视频、文本、Markdown、SQL、JSON、CSV。
- 版本有效性管理：旧版本可以标记为失效，默认隐藏失效版本。
- 文件重命名。
- 拖拽移动文件和目录。
- 支持搜索当前目录或整个项目，并按文件类型筛选。

- 文档工作区。

- 支持文件夹和文档两种节点。
- 可以按主题建立多级知识树。
- 支持在知识树里拖拽移动文件夹和文档。
- 学习统计概览：全部文档、进行中、已完成、高优先级。
- 搜索标题、分类、正文和资料链接。
- 支持按状态和内容类型筛选知识库内容。
- 新建文件夹。
- 新建文档。
- 编辑文档标题、分类、状态、优先级。
- 支持标签和文档置顶。
- 编写正文内容，适合记录学习笔记、方案和复盘。
- 正文支持 Markdown 标题、列表、待办、引用、代码块、SQL 模板、表格快捷插入。
- 记录资料链接，并一键打开外部资料。
- 自动保存文档历史快照，并支持恢复到旧版本。
- 支持最近编辑和置顶文档快速进入。
- 删除文档。
- 批量删除文档和文件夹。
- 批量移动文档和文件夹。
- 批量修改文档分类。
- 仅查看用户只能阅读文档，不能新增或修改。

### 系统管理

- 查看用户列表。
- 管理模块名称、说明和排序。
- 创建普通用户或管理员用户。
- 设置用户初始密码。
- 修改用户显示名和用户名。
- 调整普通用户和管理员角色。
- 启用或停用账号。
- 重置用户密码。
- 删除用户账号，保留文件、文档和操作历史。
- 在 `用户模块权限` 区域修改已创建用户对每个模块的权限。
- 为每个用户配置模块权限：
  - `3D 文档归档`
  - `大数据学习`
- 管理员用户默认拥有所有模块的管理权限。

## 3D 文件支持范围

第一版重点支持 3D 工作流常见格式的上传、下载、归档和版本管理。

- 3D 工程源文件：`blend`、`max`、`ma`、`mb`、`c4d`、`skp`、`spp`、`sbsar`
- 通用 3D 格式：`fbx`、`obj`、`gltf`、`glb`、`stl`、`dae`、`abc`、`usd`、`usdz`
- CAD 和工程图：`dwg`、`dxf`、`step`、`stp`、`iges`、`igs`
- 贴图和图片：`png`、`jpg`、`jpeg`、`webp`、`tif`、`tiff`、`exr`、`hdr`、`psd`
- 视频和动画预览：`mp4`、`mov`、`avi`、`webm`
- 压缩包：`zip`、`rar`、`7z`
- 文档说明：`md`、`txt`、`docx`、`xlsx`、`pdf`

当前可在线预览：

- 图片：`png`、`jpg`、`jpeg`、`webp`、`gif`、`svg`
- PDF：`pdf`
- 视频：`mp4`、`webm`、`mov`
- 文本类：`txt`、`md`、`sql`、`json`、`csv`、`tsv`、`xml`、`yaml`、`py`、`js`、`css`、`html`

`blend`、`max`、`c4d` 等软件源文件暂不在线预览，先支持上传、下载、归档和版本管理。

## 技术方案

- 后端：`FastAPI`
- 前端：`React + Vite`
- 数据库：`SQLite`
- 文件存储：服务器本地磁盘目录
- 部署建议：`Docker Compose + Nginx`

## 数据存储

本地开发时：

```text
backend/data/work_file_archive.db
backend/data/storage/files/
```

线上部署时建议：

```text
/opt/work-file-archive/storage/files/
```

上传文件会按日期和唯一 ID 存放，例如：

```text
storage/files/2026/04/29/3f5c9e2a7b1d4c9b.blend
```

数据库保存项目、目录、用户、权限、文件元信息和版本记录。

## 安全设计

- 密码加密保存，不明文存数据库。
- 登录态使用服务端 token。
- 后端接口校验登录状态。
- 后端接口校验模块权限。
- 文件下载接口校验权限，不暴露真实服务器文件路径。
- 上传文件使用系统生成的唯一文件名，避免重名覆盖和路径穿越。
- 文件保存 SHA256 校验值，用于发现重复文件和校验文件是否损坏。
- 删除文件先进入回收站。

## 本地启动

### 默认账号

```text
用户名：admin
密码：admin123
```

### 启动后端

后端默认使用 `8010` 端口，避免和其它本地项目的 `8000` 端口冲突。

```bash
cd /Users/zmd/work/work-file-archive/backend
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --host 127.0.0.1 --port 8010
```

### 启动前端

```bash
cd /Users/zmd/work/work-file-archive/frontend
npm install
npm run dev
```

前端访问地址。如果 `5173` 被占用，Vite 会自动使用 `5174`：

```text
http://127.0.0.1:5173
http://127.0.0.1:5174
```

## Docker 部署

项目已经提供第一版 Docker 部署文件：

```text
docker-compose.yml
backend/Dockerfile
frontend/Dockerfile
frontend/nginx.conf
```

服务器上拉取代码后执行：

```bash
cd work-file-archive
docker compose up -d --build
```

默认访问端口：

```text
http://服务器IP:8080
```

可以通过环境变量调整端口和默认管理员：

```bash
APP_PORT=80 \
DEFAULT_ADMIN_USERNAME=admin \
DEFAULT_ADMIN_PASSWORD=请改成强密码 \
docker compose up -d --build
```

生产数据默认挂载到项目目录：

```text
data/work_file_archive.db
data/storage/
```

请定期备份 `data/` 目录。
